# Nidhaus_UnitFrames_Config

Panel de configuración de **[Nidhaus_UnitFrames](../../../Nidhaus_UnitFrames)** para World of Warcraft 3.3.5a (WotLK).

**Autor:** Nidhaus

## Qué es

Addon complementario que contiene toda la interfaz de opciones de Nidhaus_UnitFrames: pestañas de marcos, arena, PvP y extras, gestor de temas, y la lista lateral de módulos. Va separado del addon principal para que la UI de opciones solo se cargue cuando la abrís, y no pese en memoria durante el juego.

**No funciona solo.** Necesitás tener instalado Nidhaus_UnitFrames.

## Instalación

1. Cerrá el juego.
2. Copiá la carpeta `Nidhaus_UnitFrames_Config` dentro de `World of Warcraft\Interface\AddOns\`.
3. Iniciá el juego y activá el addon en el selector de la pantalla de personajes.

## Comandos

| Comando | Qué hace |
|---|---|
| `/nufconfig` | Abre el panel de configuración |
| `/nufoptions` | Alias |

## Compatibilidad

Interface 30300 — WotLK 3.3.5a. Probado en Warmane.
